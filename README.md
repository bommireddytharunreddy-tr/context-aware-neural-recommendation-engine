# Context-Aware Neural Recommendation Engine

A deep learning recommendation system for personalized product recommendations using the H&M Personalized Fashion Recommendations dataset.

## Tech Stack

- Python
- PySpark
- TensorFlow
- TensorFlow Recommenders
- Redis
- FastAPI

## Project Goal

Build a context-aware recommendation engine using a Two-Tower neural network architecture to generate personalized product recommendations based on user behavior, item metadata, and contextual features.

## Development Plan

1. Data processing and feature engineering
2. Two-Tower recommendation model
3. Model evaluation
4. Item embeddings and ANN retrieval
5. Redis feature store
6. FastAPI recommendation API
7. Airflow pipeline
